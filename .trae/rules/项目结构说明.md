本规则只描述“每个文件夹的开发边界与内容”，不绑定具体文件名。

## 文件夹职责（必须遵守）

- 仓库根目录（入口层）
  - 只放应用装配与启动相关内容：FastAPI 应用装配、路由注册、静态资源挂载、WebSocket 连接管理与广播
  - 禁止在入口层堆采集协议、解析细节、算法细节（应下沉到 `core/`）
- `configs/`（配置层）
  - 放运行配置与配置加载/校验逻辑
  - 所有可变参数必须来自配置；禁止在代码里硬编码通道数/采样率/设备参数/流控参数
  - 禁止 import `core/`、`web/`、`ref/`
- `core/`（核心层）
  - 放可复用的业务核心：采集控制编排、数据流转/缓冲/节流、调试事件等
  - 禁止依赖 FastAPI/WebSocket/前端（Web 相关只允许在入口层）
- `core/ble/`（采集与协议层：BLE）
  - 只做采集与协议解析：获取字节流/帧、解析为结构化样本、发布到 LSL、产生调试事件
  - 禁止写任何 WebSocket 广播、HTTP 路由、静态文件路径处理等
- `core/signal/`（可选：算法层）
  - 放在线算法/信号处理（与采集层解耦）；输入输出使用结构化数据或 LSL
- `web/`（前端层）
  - 只放 HTML/CSS/JS 等静态资源
  - 与后端交互只能通过 HTTP API + WebSocket；禁止假设后端内部模块路径
- `docs/`（资料层）
  - 放协议文档、说明文档等外部资料
  - 运行时不可依赖
- `ref/`（历史参考层）
  - 旧项目只读参考；禁止运行时依赖、禁止 import
- `.trae/`（工程规则层）
  - 放 IDE/规则配置；运行时不可依赖

## import 方向（强约束）

- 入口层 → `configs/`、`core/`（允许）
- `configs/` → 只允许标准库/第三方库（不允许依赖本项目其他层）
- `core/` → 允许依赖 `configs/`（仅用于读取配置类型/结构），禁止反向依赖入口层与 `web/`
- `web/` → 不允许 import Python；只通过网络协议与后端交互
