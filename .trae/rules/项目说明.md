# BHB-EEG Station

## 一句话

基于 `ref/` 重构在 Windows 11 上运行的 Web 上位机：负责 EEG 采集控制、阻抗检测、EEG 存取、在线数据流转（LSL）、以及浏览器实时可视化（WebSocket）。

## 必须做到

- 8/16 通道模式只能通过配置选择，禁止硬编码
- 采集与 Web 解耦：采集进程稳定产出数据；Web 只消费并展示
- 开发的所有功能可以离线使用，无需联网下载资源

## 不做

- 桌面 GUI（PyQt/PySide 等）
- 运行时依赖 `ref/`（旧项目代码只用于“看实现思路/协议细节”），其中的算法解析函数经过实测可以保留，但是蓝牙连接和进程管理需要重构
